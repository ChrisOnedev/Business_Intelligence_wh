Building a modern data werehouse with SQL SERVER, incluiding ETL processs, data modeling and analytics


#### Specifications
- **Data Source**: Import data from two source system (ERP and CRM) provided as CSV files.
- **Data Quality**: Cleanes and resolves data quality prior to analysis
- **Integration**: Combine both source into single, user-friendly data model designed for analytical queries
- **Scope**: Focus on the latest dataset only; historical of data is no required.
- **Documentation**: Provide clear documentation of the data model to support both business stakeholders and analytics teams.
